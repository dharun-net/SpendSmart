# SpendSmart — Team Zenova

**Track your money. Control your spending. Build better habits.**

SpendSmart is a student-focused expense tracker and monthly budget dashboard built with HTML, CSS and JavaScript.

## Features
- Add expenses with amount, category, date and description
- Save transactions in browser LocalStorage
- Monthly budget and remaining-balance tracking
- Budget progress indicator and overspending warning
- Category-wise doughnut chart
- Recent transaction list with delete option
- Responsive layout for desktop and mobile

## Run the project
Open `index.html` in a modern browser. Chart.js and Google Fonts load from their public CDNs, so an internet connection is needed for those visual extras. Expense tracking itself works in the browser.

## Publish with GitHub Pages
1. Create a public GitHub repository named `SpendSmart`.
2. Upload **all four files** (`index.html`, `style.css`, `script.js`, `README.md`) to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch **main** and folder **/(root)**, then click **Save**.
6. Wait a few minutes and refresh the Pages section. GitHub will show your live website URL.

## Important
Your expenses are saved only in the browser where you enter them. They are not synced between devices or shared with a bank account.
